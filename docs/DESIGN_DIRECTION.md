# BM Visuals — Design Direction

## 1. Creative North Star

BM Visuals should feel like an independent digital studio operating between:

EDITORIAL DESIGN  
×  
FASHION CULTURE  
×  
CREATIVE TECHNOLOGY  
×  
DIGITAL CRAFT

The website should feel more like a digital flagship or digital magazine than a conventional agency website.

---

# 2. Emotional Target

The user should experience the site in roughly this order:

1. Curiosity
2. Visual attraction
3. Recognition of craft
4. Understanding of BM
5. Trust
6. Desire to explore work
7. Desire to start a conversation

The site should feel confident rather than loud.

---

# 3. Core Adjectives

Primary:

- editorial
- premium
- sharp
- expressive
- modern
- cinematic
- intentional
- crafted

Secondary:

- experimental
- artistic
- technical
- cultured
- youthful

Avoid feeling:

- corporate
- generic
- childish
- over-futuristic
- cyberpunk
- SaaS-like
- gimmicky

---

# 4. Visual Foundation

Primary visual foundation:

- black
- white
- warm neutrals
- project-specific colors

BM should not rely on a permanent rainbow gradient identity.

Projects may temporarily introduce strong colors.

The portfolio should feel like different visual worlds existing inside one BM framework.

---

# 5. Typography Direction

Typography is one of the main visual elements.

Use typography as composition.

Prefer:

- large display type
- editorial scale changes
- strong contrast between display and information text
- oversized statements
- restrained body text
- structured project metadata

Possible combination:

Display:
modern grotesk / editorial sans

Body:
neutral highly readable sans

Optional accent:
serif used sparingly for editorial contrast

Do not use too many typefaces.

Recommended maximum:

2 primary type families
+ optional controlled accent

---

# 6. Typography Behavior

Large headings may:

- fill the viewport
- crop against edges
- reveal by mask
- respond subtly to scroll
- overlap project imagery
- create hierarchy through scale

Body copy should remain highly readable.

Do not sacrifice usability for typography experiments.

---

# 7. Grid

Use a strong underlying grid.

Recommended desktop:

12-column grid.

Allow controlled asymmetry.

Examples:

- text occupying 4 columns
- project media occupying 7–8 columns
- intentionally empty columns
- offset layouts

Not every section needs to be centered.

---

# 8. Layout Philosophy

Avoid repeating identical cards.

Each flagship project may have its own composition.

However, all projects should share:

- consistent metadata
- spacing logic
- typography system
- transition language

Homepage should feel curated rather than templated.

---

# 9. Image Direction

Project media should dominate.

Prefer:

- full-bleed image/video
- strong crop
- large mockups
- interface details
- editorial framing
- device context only where useful

Avoid:

- excessive device mockups
- generic floating browser frames
- low-resolution screenshots
- tiny project thumbnails

---

# 10. Homepage Visual Rhythm

Homepage should alternate between:

BIG / IMMERSIVE

and

QUIET / INFORMATIONAL

Example rhythm:

Hero
↓
quiet positioning statement
↓
large project
↓
large project
↓
quiet capabilities
↓
experimental project
↓
studio statement
↓
strong final CTA

This creates pacing.

---

# 11. Interface Chrome

Navigation and controls should be restrained.

Prefer:

- compact navigation
- simple labels
- subtle borders
- minimal buttons
- text-based CTAs
- strong hover feedback

Avoid:

- excessive rounded buttons
- large navigation bars
- unnecessary UI panels

---

# 12. Button Direction

Buttons should feel integrated into typography.

Examples:

Start a project ↗

View project ↗

Explore work →

Avoid oversized SaaS CTA buttons unless composition demands it.

---

# 13. Project Presentation

Selected Work is the visual center of BM.

Homepage target:

3–4 flagship projects.

Each flagship project should have:

- project number
- title
- category
- year
- short descriptor
- visual
- intentional interaction

Projects should not simply be placed in identical cards.

---

# 14. Case Study Direction

Case study pages should feel editorial.

Suggested structure:

Hero
→ Context
→ Creative Direction
→ Experience
→ Visual System
→ Website / Interface
→ Details
→ Next Project

Use large visual breaks between text sections.

---

# 15. Lab Direction

BM Lab should be more experimental than the commercial portfolio.

Possible content:

- WebGL tests
- typography studies
- concept websites
- speculative fashion experiences
- 3D experiments
- redesign concepts
- generative visuals
- interface experiments

BM Lab can intentionally break more layout rules.

---

# 16. Motion Personality

Core phrase:

SLOW CONFIDENCE

Motion should feel controlled and expensive.

Preferred behavior:

- smooth
- deliberate
- responsive
- slightly cinematic

Avoid sluggishness.

---

# 17. Motion Examples

Good:

- title mask reveal
- project image slowly scaling into position
- visual continuity during page transitions
- subtle image parallax
- contextual cursor states
- text shifting slightly during scroll
- controlled horizontal motion

Bad:

- everything fading upward
- random 360 rotations
- continuous bouncing
- excessive cursor trails
- particles everywhere
- long loading animations

---

# 18. 3D / WebGL

WebGL is a supporting capability, not the identity itself.

Use only where it creates memorable value.

Potential usage:

- hero signature object
- BM Lab
- special flagship project
- transition experiment

Never make every section a WebGL scene.

---

# 19. Reference Benchmark

Lusion is a benchmark for:

- ambition
- polish
- creative coding quality
- project storytelling
- motion
- digital presence

BM should not become a Lusion clone.

BM should lean more toward:

EDITORIAL / FASHION / BRAND

while Lusion often leans more strongly toward:

3D / CREATIVE TECHNOLOGY / EXPERIMENTATION

---

# 20. Visual Success Test

Before approving a section ask:

1. Does this feel intentionally designed?
2. Could this belong to 100 other agencies?
3. Is the typography strong enough?
4. Is the project media doing enough work?
5. Is animation improving the experience?
6. Does this attract the type of client BM wants?
7. Does mobile still feel premium?

If the answer to #2 is yes, redesign it.
