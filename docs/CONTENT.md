# CONTENT RULES

Avoid:

- empty superlatives
- "world-class"
- "industry-leading"
- "award-winning" unless true
- "revolutionary"
- generic AI language
- generic transformation language
- fake urgency
- fake scarcity
- fake statistics

Writing style:

- concise
- confident
- editorial
- clear
- understated
- premium
