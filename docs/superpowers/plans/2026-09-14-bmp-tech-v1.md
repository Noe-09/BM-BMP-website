# BMP Tech V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current generic `/bm-tech` service page with the approved BMP Tech V1 “Systems in Motion” observatory: a distinctive, truthful, responsive systems experience centered on one flagship business workflow, a short signature boot sequence, human decision choreography, evidence, capability families, and a technical register.

**Architecture:** Keep `/bm-tech` as the only public Tech route for V1. Use route-scoped CSS plus DOM/SVG, a data-driven `content/tech.ts`, one narrow client journey controller, and server-rendered semantic content around the visual system. Preserve Gateway, BM Visual, BMP Creator, shared shell, and production root; reuse only shared brand/site primitives.

**Tech Stack:** Next.js 16.3.1, React 19.2.8, TypeScript 5, CSS, SVG, native browser APIs, existing Node test runner. Three.js is installed but is not part of the default implementation.

**Spec:** `docs/superpowers/specs/2026-09-14-bmp-tech-v1-design.md`

## Global Constraints

- Implementation branch: `feat/bmp-tech-v1`, created from the latest `origin/main` before any source edit.
- Public route remains exactly `/bm-tech`.
- Read `CLAUDE.md`, the canonical BMP brand/content source, relevant `docs/bmp-content/`, and the local Next.js 16 guide under `node_modules/next/dist/docs/` before code.
- Do not modify Gateway except for a strictly required shared-navigation correction approved by the user.
- Do not redesign BM Visual or BMP Creator.
- BMP Tech is business systems and practical tools, not generic AI/software outsourcing.
- Flagship proof: **AI Social Media Posting System**.
- Truth model: real core + clearly labeled designed future layers.
- Never fabricate metrics, clients, outcomes, uptime, usage, integrations, production maturity, or implementation evidence.
- `VERIFIED` is allowed only when source evidence is found and recorded during the implementation audit.
- If no source supports a supposed active/verified flagship feature, render it as `PLANNED` or stop and report the truth gap; do not guess.
- Systems Observatory visual direction: system state, routing, dependency, human decision, output, evidence.
- Avoid cyberpunk, terminal walls, fake code, Matrix text, glowing AI orbs, glass dashboards, floating SaaS cards, integration-logo walls, fake metrics, blue-purple “AI” gradients, Creator portals, and BM Visual case-study grammar.
- DOM + SVG first. Do not add GSAP, Lenis, D3, a graph library, or another animation dependency without a demonstrated limitation and explicit approval.
- Native scrolling only; no scroll-jacking.
- First-session Tech boot target: ~700–1200 ms. Returning session: skip or ~0–300 ms reacquire.
- Reduced motion must preserve all causal information.
- Mobile is a first-class causal recomposition, not a scaled desktop graph.
- Release checks: `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`, `git diff --check`.
- Visual QA: 1440, 1024, 768, 390, 360 widths; DPR2; slow scroll; fast scroll; reverse; reload; reduced motion; keyboard; session-return; console/overlay; horizontal overflow.
- Quality benchmark is Lusion-level craft, not Lusion imitation.

```ts
import type { TechPhase } from "@/content/tech";

export const TECH_PHASES: readonly TechPhase[] = [
  "observe",
  "ingest",
  "normalize",
  "orchestrate",
  "assist",
  "checkpoint",
  "execute",
  "return",
  "evidence",
  "spectrum",
  "register",
  "close",
];

export function clamp01(value: number) {
  return Math.min(1, Math.max(0, value));
}

export function dampTechProgress(
  current: number,
  target: number,
  deltaSeconds: number,
  lambda = 16,
) {
  const alpha = 1 - Math.exp(-lambda * Math.max(0, deltaSeconds));
  return current + (target - current) * alpha;
}

export function getTechPhase(progress: number) {
  const clamped = clamp01(progress);
  const scaled = clamped * TECH_PHASES.length;
  const index = Math.min(TECH_PHASES.length - 1, Math.floor(scaled));
  const phaseStart = index / TECH_PHASES.length;
  const phaseEnd = (index + 1) / TECH_PHASES.length;
  const phaseProgress =
    phaseEnd === phaseStart
      ? 1
      : clamp01((clamped - phaseStart) / (phaseEnd - phaseStart));

  return {
    phase: TECH_PHASES[index],
    phaseProgress,
  };
}
```
