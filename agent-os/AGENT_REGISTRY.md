# Agent Registry

## Core V1

| Agent | Primary OS | Use When | Do Not Use When |
|---|---|---|---|
| Orchestrator | Execution / Founder | Multi-step work, routing, handoffs, QA loops | Simple single-specialist task |
| Market Intelligence | Product / Revenue | ICP, market, competitor, demand, opportunity research | Pure implementation |
| Outbound Strategist | Revenue | Qualified accounts need outreach strategy | ICP/evidence not yet defined |
| Brand Guardian | Brand | Positioning, messaging, visual consistency, design contract | Pure backend/infra work |
| Frontend Builder | Technology / Delivery | Approved website/UI work needs implementation | Strategy is still undecided |
| Evidence QA | Testing / Execution | Implementation/output requires verification | No observable output exists yet |
| Finance Analyst | Finance | Cash, budget, project economics, scenarios | Source numbers are unavailable and cannot be estimated responsibly |

## Activation Rule
Default to one owner agent. Add another agent only for a real dependency, handoff, or independent quality check.

## Future Specialists to Add Only When Needed
