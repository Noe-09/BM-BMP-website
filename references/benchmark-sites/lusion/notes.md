# Lusion — BM Visuals Reference Notes

## Purpose

Lusion is used as a benchmark for quality, ambition and creative digital craft.

It is NOT a design template.

BM Visuals must develop its own identity.

---

# What We Like

## 1. Website as Proof

The website itself demonstrates the studio's capability.

The visitor does not only read about creative technology.

They experience it.

BM should adopt this principle.

---

## 2. Project-First Storytelling

Work is treated as one of the primary storytelling devices.

Projects are not hidden inside small portfolio cards.

BM should make Selected Work a central part of the homepage.

---

## 3. Strong Typography

Large typography creates:

- hierarchy
- rhythm
- confidence
- visual identity

BM should use typography as composition rather than decoration.

---

## 4. Cinematic Pacing

The site alternates between:

- visual intensity
- quieter informational moments

BM should adopt this rhythm.

---

## 5. Meaningful Motion

Animation helps create:

- continuity
- discovery
- hierarchy
- storytelling

BM should not animate every object.

---

## 6. Project Transitions

Visual continuity between portfolio previews and project pages creates a premium experience.

BM should explore similar principles without copying exact transitions.

---

## 7. Experimental Technology

Creative technology is visible but remains part of the experience.

BM can experiment with:

- WebGL
- motion
- creative coding
- 3D

but only where it creates meaningful value.

---

# What We Must NOT Copy

Do not reproduce:

- exact homepage composition
- exact navigation
- exact typography
- exact WebGL scenes
- exact 3D objects
- exact page transitions
- exact project layouts
- exact animation timings
- exact copy

Lusion is an inspiration benchmark, not a visual template.

---

---

# BM Visual Principle

The goal is NOT:

"Make BM look like Lusion."

The goal is:

"Make BM feel as intentional, polished and ambitious as Lusion while developing a clearly different BM visual language."

---
